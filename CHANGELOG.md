# Changelog

## 1.0.0

- First public release of the GEO Skill Kit as skill `geo-audit`.
- Five phases from audit to verified fix, with `scripts/verify-geo.mjs` (Node 18 or newer, no dependencies).
- Templates for robots.txt, llms.txt, JSON-LD (Organization, WebSite, SoftwareApplication, FAQ) and project rules.
- Packaged as a Claude Code plugin (`geo-skill-kit`) and plugin marketplace (`red-center-studio-skills`).
